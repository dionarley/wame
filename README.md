# wame

Gerador de links diretos para o WhatsApp (wa.me). SPA em Vanilla JS, sem dependências de runtime.

## Uso rápido

```bash
npm install
npm run dev
```

Abra `http://localhost:5173`.

## Em produção

```bash
docker compose up -d
```

Acesse `http://localhost:8080`.
